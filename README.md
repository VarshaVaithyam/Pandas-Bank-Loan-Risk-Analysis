# 🏦 Bank Loan Risk Analysis

## 📌 Project Overview

This project analyzes a bank loan dataset to identify patterns in loan applications, borrower characteristics, credit scores, interest rates, and loan-related attributes. The goal is to perform data cleaning, exploratory data analysis (EDA), visualization, and derive meaningful business insights.

---

## 🎯 Objectives

- Understand the dataset
- Perform data cleaning
- Analyze borrower information
- Explore relationships between variables
- Visualize important trends
- Generate business insights

---

## 🛠 Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook
- Git & GitHub
